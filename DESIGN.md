# Example interface

A developer-facing upload lab with scenario navigation, an editable image field, canonical form state and replacement receipts. The image control uses a dashed add tile, a 4:3 preview, zinc borders, emerald status/progress and compact actions. The example customizes its copied instructions without changing the distributed template.

The old image stays visible until a successful replacement. Do not add automatic deletion, cropping or storage management to this UI. Keep the native file input keyboard accessible, described errors visible, and cancel/retry available. Stack the two columns on narrow screens. Browser, accessibility and visual verification status belongs in docs/verification.md; do not infer it from design intentions.
